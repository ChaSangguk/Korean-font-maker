# 한글 폰트 메이커 — 유즈 케이스 초안 v0

## 1. 목적

이 문서는 일반 사용자가 이 제품으로 끝내고 싶은 일을 정의한다. 화면이나 기술 구현보다 사용자의 목표와 성공 결과를 먼저 확정한다.

## 2. 사용자 역할

| 역할 | 설명 |
|---|---|
| 창작자 | 게임·영상·굿즈 등에 쓸 자기만의 한글 폰트를 만들고 싶은 일반 사용자 |
| 시스템 | 작성 시트 사진을 처리하고 자모를 조합해 폰트 파일을 만드는 프로그램 |

## 3. 핵심 유즈 케이스

### UC-01. 종이에 쓴 글씨로 새 폰트 시작하기

**목표:** 창작자가 복잡한 폰트 지식 없이 자신의 손글씨를 프로젝트에 가져온다.

**사전 조건:** 창작자는 작성 시트를 인쇄했거나 디지털 기기에서 열 수 있다.

**기본 흐름:**

1. 창작자가 새 폰트 프로젝트를 만든다.
2. 시스템이 작성 시트와 작성 방법을 제공한다.
3. 창작자가 시트의 안내된 칸에 글자를 그린다.
4. 창작자가 시트를 사진으로 찍어 업로드한다.
5. 시스템이 사진의 시트 위치를 보정하고 각 입력 칸을 추출한다.
6. 시스템이 추출 결과와 대표 음절 미리보기를 보여 준다.
7. 창작자가 결과를 확인하고 프로젝트에 저장한다.

**성공 결과:** 프로젝트 안에 재사용 가능한 자모 또는 자모 조합 데이터가 저장된다.

**예외:** 사진이 흐리거나 마커가 보이지 않으면 시스템은 재촬영 방법을 안내한다.

### UC-02. 자동으로 만들어진 한글 결과 확인하기

**목표:** 창작자가 자신이 만든 스타일이 실제 문장에서 어떻게 보이는지 확인한다.

**기본 흐름:**

1. 창작자가 미리보기 화면을 연다.
2. 시스템이 대표 조합(`가`, `각`, `고`, `광`, `귀` 등)과 기본 문장을 생성한다.
3. 창작자가 게임 대사 또는 원하는 문장을 입력한다.
4. 시스템이 해당 문장을 새 폰트로 표시한다.
5. 창작자가 어색하거나 겹치는 글자를 선택한다.

**성공 결과:** 창작자는 자신의 폰트가 실제 사용 문맥에서 읽히는지 판단할 수 있다.

### UC-03. 어색한 글자 고치기

**목표:** 창작자가 자동 조합 결과 중 마음에 들지 않는 부분만 간단히 수정한다.

**기본 흐름:**

1. 창작자가 미리보기에서 문제 음절을 선택한다.
2. 시스템이 해당 음절을 구성하는 초성·중성·종성과 배치 상태를 표시한다.
3. 창작자가 자모의 위치·크기·여백을 수정하거나, 원본 입력을 다시 그린다.
4. 창작자가 변경 범위를 고른다: 이 음절만 또는 같은 조합 유형 전체.
5. 시스템이 결과를 다시 생성하고 문장 미리보기를 갱신한다.

**성공 결과:** 창작자는 전체 폰트를 다시 만들지 않고 문제를 보정한다.

### UC-04. 게임에 넣을 폰트 파일 내보내기

**목표:** 창작자가 만든 폰트를 자신의 게임이나 개인 프로젝트에 실제로 적용한다.

**사전 조건:** 창작자는 생성 결과와 경고를 검토했다.

**기본 흐름:**

1. 창작자가 내보내기를 선택한다.
2. 시스템이 폰트 이름, 제작자, 버전, 사용 라이선스 문구를 묻는다.
3. 시스템이 누락된 자모, 잘림, 겹침 같은 치명적 경고를 보여 준다.
4. 창작자가 경고를 수정하거나 검토 후 계속한다.
5. 시스템이 TTF 파일을 생성한다.
6. 시스템이 설치 및 게임 엔진 적용 방법을 안내한다.

**성공 결과:** 창작자는 설치 또는 게임 프로젝트에 넣을 수 있는 폰트 파일을 받는다.

### UC-05. 나중에 작업 이어 하기

**목표:** 창작자가 중간에 멈춘 폰트 작업을 잃지 않고 계속한다.

**기본 흐름:**

1. 창작자가 기존 프로젝트를 연다.
2. 시스템이 원본 사진, 추출된 자모, 조합 규칙, 개별 보정 내용을 불러온다.
3. 창작자가 특정 자모 또는 음절을 수정한다.
4. 시스템이 영향을 받는 미리보기를 갱신한다.
5. 창작자가 저장 또는 재내보내기한다.

**성공 결과:** 이전 보정 내용이 유지되고, 변경된 결과물만 다시 만들 수 있다.
