# 한글 폰트 메이커 아이디어 정리

## 어떤 프로젝트인가?

일반 사용자도 자신이 직접 쓴 글씨로 한글 폰트를 쉽게 만들 수 있게 해주는 프로그램이다. 게임이나 영상, 개인 창작물에 자신만의 글꼴을 넣고 싶은 사람을 주요 사용자로 생각하고 있다.

## 왜 만들려고 하는가?

한글 폰트는 최대 11,172개의 완성형 글자를 만들어야 해서 개인이 직접 제작하기 어렵다. 하지만 한글은 초성·중성·종성을 조합하는 문자이므로, 자주 쓰이는 대표 글자에서 자모 조각을 분리한 뒤 다시 조합하면 작업량을 크게 줄일 수 있다고 생각했다.

## 현재 생각한 방식

1. 프로그램이 `가`, `각`, `고`, `과`, `구`, `궈` 같은 대표 글자를 순서대로 보여준다.
2. 사용자가 화면에 글자를 직접 쓰거나, 종이에 쓴 글자를 사진으로 올린다.
3. 프로그램이 글자를 초성·중성·종성 조각으로 나눈다.
4. 분리한 조각을 5가지 글자 배치 형태에 맞춰 다시 조합한다.
5. 만들어진 글자를 문장으로 미리 확인하고 TTF 폰트 파일로 저장한다.

현재 계산으로는 완성형 11,172자를 모두 직접 쓸 필요 없이, 대표 글자 약 198개에서 초성 190개·중성 42개·종성 54개 조각을 얻어 전체 한글을 조합할 수 있다.

## 우선 만들어 볼 기능

- 대표 글자 목록과 단계별 입력 화면
- 화면 직접 그리기 및 사진 업로드
- 완성 글자를 자모 조각으로 자동 분리
- 모음과 받침에 따른 5가지 배치 방식
- 입력 문장으로 결과 미리보기
- TTF 폰트 파일 생성

## 이 프로젝트의 장점

- 전문 폰트 편집기를 몰라도 사용할 수 있다.
- 11,172자를 하나씩 그리는 것보다 작업량이 적다.
- 인디 게임이나 개인 창작물에 개성 있는 한글 폰트를 사용할 수 있다.
- 이후 손글씨 보정이나 자동 조합 품질 개선 기능으로 확장할 수 있다.

## 팀에서 더 이야기해 볼 것

- 대표 글자 198개가 일반 사용자에게 너무 많지는 않은가?
- 종이에 작성한 시트를 촬영하는 방식과 화면에 직접 그리는 방식 중 어느 쪽을 중심으로 할 것인가?
- 자동 조합 결과가 어색할 때 어떻게 쉽게 수정하게 할 것인가?
- 첫 번째 목표를 손글씨 폰트로 할지, 픽셀 폰트로 할지 결정해야 한다.
- Unity, Godot 등 어떤 게임 환경에서 먼저 테스트할 것인가?
