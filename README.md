# 한글 폰트 메이커 MVP

일반 사용자가 자모를 직접 그리거나 사진으로 가져와 한글 조합을 미리 보고 TTF 파일로 내보내는 로컬 웹 MVP입니다.

## 실행

```powershell
python -m unittest discover -s tests -v
python app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## 현재 MVP 범위

- 현대 한글 음절의 분해·조합과 모음/받침별 초성 유형 선택
- 고정 입력 칸에서 사진의 어두운 획 추출 및 64×64 정규화
- 캔버스에 `가`, `각`, `과`, `궈` 같은 완성 글자를 쓰거나 사진으로 업로드
- 완성 글자를 슬롯 기준으로 초성·중성·종성 조각으로 자동 분리 저장
- 286개 조각을 모두 수집하는 최소 198개 대표 완성 글자 목록과 자동 다음 글자 이동
- 512×512 고해상도 입력 캔버스와 획 단위 Undo/Redo
- 필요할 때 자모 조각을 직접 입력하는 고급 모드
- 형태 1, 2-1, 2-2, 3-1, 3-2와 받침 유무에 따른 고정 슬롯 조합
- 초성 190개, 중성 42개, 종성 54개 입력 조각 선택
- 입력 문장 미리보기
- 현대 한글 11,172자를 포함한 TTF 내보내기

작성 시트 전체의 모서리 마커 인식·원근 보정과 한 장의 시트에서 다수 칸을 자동 분할하는 기능은 다음 반복 단계의 범위입니다.
